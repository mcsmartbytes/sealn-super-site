# Changes Made - January 7, 2026

## Overview
Fixed multiple issues across sealn-super-site and area-bid-helper for investor presentation readiness.

## sealn-super-site Fixes

### 1. Inquiries Page - Database Fix
**Problem:** "Failed to load inquiries" error
**Cause:** App was configured to use `sealn` schema, but Supabase API only exposes `public` schema by default. Also, table was named `contacts` not `contact_request`.
**Fix:**
- Changed `src/utils/supabase.ts` to use `public` schema
- Updated `src/app/admin/inquiries/page.tsx` to query `contacts` table

### 2. SiteSense Page - 404 Error
**Problem:** Embedded SiteSense showed 404
**Cause:** URL pointed to non-existent deployment (`sealing-striping-michelles-projects-54c2f766.vercel.app`)
**Fix:** Replaced with demo mode (see below)

### 3. Demo Mode for Embedded Apps
**Problem:** Books, CRM, and SiteSense pages required separate authentication when embedded
**Solution:** Created static demo mockups with realistic sample data

#### SiteSense Demo (`src/app/admin/sitesense/page.tsx`)
- Job tracking dashboard
- Stats: Active Jobs (12), Completed (8), Revenue ($47,250), Scheduled Hours (156)
- Sample jobs: Walmart, Target, CVS, Home Depot
- Feature cards: Job Management, Crew Scheduling, Real-time Analytics

#### Books Demo (`src/app/admin/books/page.tsx`)
- Financial dashboard
- Stats: Revenue ($156,780), Expenses ($67,450), Profit ($89,330), Pending ($12,500)
- Accounts: Business Checking, Savings, Credit Card
- Recent transactions with categories
- Feature cards: P&L Reports, Invoicing, Tax Ready, Bank Sync

#### CRM Demo (`src/app/admin/crm/page.tsx`)
- Lead management dashboard
- Stats: Total Leads (47), Hot Leads (12), Pipeline ($425,000), Conversion (34%)
- Lead table with status indicators (Hot/Warm/New/Cold)
- Activity feed: calls, emails, meetings, notes
- Feature cards: Contact Management, Sales Pipeline, Follow-up Reminders, Reports

### 4. Area Helper Integration
**Problem:** "Send Quote" wasn't sending data to estimates
**Cause:** Data format mismatch - area-bid-helper used `qty`, sealn-super-site expected `measurementValue`
**Fix:**
- Updated `src/app/admin/area-helper/page.tsx` to handle new line items format
- Added `QuoteLine` interface with proper field mapping
- Updated success banner to show quote total and address
- Changed iframe URL to include `?industry=sealing-striping&embedded=true`

## area-bid-helper Fixes

### 1. Service Switching Bug
**Problem:** Switching services reassigned all existing drawings to new service
**Fix:** Updated `src/lib/quote/useSyncMeasurements.ts`
- Added `shapeServiceMap` ref to track original service per shape
- Removed `geometries` from useEffect dependencies to prevent loops

### 2. Save Draft Not Working
**Problem:** Save Draft button did nothing
**Fix:** Implemented `handleSaveDraft` in `src/app/quote/map/page.tsx`
- Saves to localStorage as `QUOTE_DRAFTS`
- Stores address, industry, geometries, lines, total
- Keeps last 10 drafts

### 3. Drawing Mode Issues
**Problem:** Drawing tools switched to hand/pan mode unexpectedly
**Fix:** Updated `src/components/MapView.tsx`
- Freehand mode now keeps MapboxDraw in `draw_polygon` mode
- Custom mouse handlers work without MapboxDraw interference

### 4. Embedded Mode Support
**Problem:** No way to skip onboarding when embedded
**Fix:**
- `src/app/onboarding/page.tsx` - Accept `?industry=` URL param
- `src/app/quote/map/page.tsx` - Check URL params for industry
- `handleSendQuote` - Uses postMessage API when embedded
- Maps `qty` to `measurementValue` for parent site compatibility
